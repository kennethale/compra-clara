# Datos del equipo

Pon aquí los archivos ya depurados:
- `focus-group/`: transcripción, notas o matriz de hallazgos, citas con participante y minuto, número de participantes y fecha.
- `encuesta/`: exportación de Google Forms (`.csv` o `.xlsx`), con el cuestionario y la fecha de cierre.
- `salida/`: lo que genera Codex, como `compra-clara-respaldo.json`, el respaldo que se restaura en la página.

**Privacidad:** el repositorio es público. Por eso `focus-group/` y `encuesta/` están en `.gitignore`: sus archivos se quedan en tu computadora y Codex los lee localmente, pero no se suben a GitHub. Si aun así decides subir algo, quita nombres completos, correos, teléfonos y cualquier dato que identifique a los participantes. Usa códigos como P1, P2…
